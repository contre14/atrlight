# Responsive Polish V13 — Services hover menu

- Desktop/laptop users can now open the Services mega-menu by hovering over **Services**.
- Added a small invisible hover bridge between the navigation label and the dropdown so the menu stays open while the cursor moves into it.
- Hovering also rotates the Services chevron to show that the menu is active.
- Mobile/tablet navigation remains tap/click controlled.
- No other layout, content, scroll behavior, or responsive styling was changed.
